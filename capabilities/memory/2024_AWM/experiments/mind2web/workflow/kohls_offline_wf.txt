## store_locator
Given that you are looking for a Kohl's store location, this workflow finds a store based on city, state, or zip code.
1. [link] Store Locator -> CLICK
2. [textbox] Please enter City, State, or Zip Code -> TYPE: {location}
3. [div] {location}, US -> CLICK

These workflows cover the common actions across the tasks, ensuring non-overlapping, commonly reused sequences.
