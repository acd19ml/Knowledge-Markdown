# Research Direction

## 源头不可见的行为塑形（behavior shaped by invisible origins）

关联主张：
- [Theory Map](../theory_map.md)

### Goal

研究过去经验如何持续塑造当前行为倾向，同时使这些倾向的起点不必始终保持可见。

### Problem Reframing

问题不只是“过去经验是否还在影响现在”，而是当这种影响已经表现为当前行为结构的一部分时，系统往往只能看到“现在自己会怎么做”，却看不到这些倾向最初来自哪里。

### Core Hypothesis

很多当下行为并不是通过显式回忆源头事件才产生的，而是过去经验已经把某些反应方式、偏好方向或判断惯性编织进了当前倾向之中。

因此，行为可以持续存在，而起源可以变得不可见。

### Requirements

- 当前行为倾向可以在不显式回忆源头事件的情况下运行
- 系统应能表现出稳定的行为风格或判断惯性，而不是一次性反应
- 系统对这些倾向的起源只能部分解释，甚至无法解释
- 后续经验可以继续重塑这些倾向，而不是把它们固定成不可变化的硬规则

### Evaluation

评估重点不应只是系统能否回溯出行为的起点，而应同时看两件事：

- 系统是否已经形成稳定的当前行为倾向
- 系统对这些倾向起源的解释是否只能部分成立，甚至并不稳定

一个更接近这条理论的系统，应该允许“行为风格是稳定的，但起源说明并不完整”。

关键判据包括：

- `behavioral consistency`
  - 系统在多个后续情境中表现出相对稳定的行为风格或判断惯性

- `origin opacity`
  - 系统无法总是清楚指出这些倾向最初来自哪一个具体 `episode`

- `action without source reconstruction`
  - 系统可以在不重建完整源头解释的前提下继续一致地行动

- `continued reshaping`
  - 后续经验能够继续改变这些倾向，而不是让早期来源永久冻结为单一行为模式

### Open Questions

- 什么样的稳定行为倾向才应被视为“被过去塑形的结果”，而不是局部任务策略或短期适应
- 如何区分“起源自然变得不可见”与“系统只是丢失了追溯能力”
- 后续经验应如何继续重塑行为风格，同时保持系统行为上的连续性
